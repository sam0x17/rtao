# M1-10 network inputs

`Network` resolves the labels, exact endpoints and local environment override
from `rtao_catalog::py`. Fallback and archive pools retain the extracted order.
Custom endpoints have one primary, no archive pool and no pinned identity.
Public presets use the public pacing defaults. Diagnostic endpoint formatting
redacts credentials and query parameters; unknown labels use Python's quoting.

`cargo xtask pin --networks` reads `chain_getBlockHash(0)` twice for finney,
test and devnet using HTTPS counterparts of the extracted WSS endpoints.
Both responses must agree and match any previously recorded identity. The
command writes the derived client module before publishing `upstream.toml`.
`pin --networks --check` verifies exact generated bytes offline; ordinary
`pin --check` also checks these inputs.
