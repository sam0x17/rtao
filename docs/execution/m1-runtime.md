# Runtime generation and verification

`cargo xtask regen` reads the immutable Finney V15/V16 metadata files named by `upstream.toml`. It verifies metadata hashes and index provenance before parsing, uses the core runtime and staged metadata IR for V15, and reads V16 API versions and call deprecations with `frame-metadata`. It performs no network I/O or Python execution.

The configured scope includes Python's 13 `COVERED_PALLETS` plus System, Timestamp, Aura, Drand, and Sudo. Every advertised runtime API is recorded. Generated output contains 282 typed call builders, 371 storage entries, 125 constants, 280 events, 124 runtime API methods across 25 API traits, and all 405 module errors. It also records signed extensions in their encoding order, all pallet names and indices, 77 selective metagraph field indices, eleven typed semantic field contracts, and exact model hashes. Selective indices come from the vendored Rust enum; its order must agree with the source's `from_index` match.

Regeneration also parses all five Python `_generated` files with the bounded Rust parser. The actual pinned metadata agrees with their 311 calls and argument order, 402 storage names and value identities, 136 constant names, 124 API method names, and 405 error names, indices, and documentation. The Rust scope deliberately covers fewer pallet descriptors than the Python inventory; the complete cross-check still covers every Python row.

Price overrides are explicit for seven SubtensorModule arguments. All seven Contracts `storage_deposit_limit` arguments are explicitly amounts, including deprecated weight variants and `upload_code`. A new price-named or limit-named balance argument without a decision makes regeneration fail. Metadata's optional and compact wrappers are followed before applying this check. Storage's zero-account override applies to every Default AccountId32 value with 32 zero default bytes. The actual metadata test finds exactly Owner, SubnetOwner, SubnetOwnerHotkey, and Keys; missing values decode to the zero SS58 account through the core and to 32 zero bytes through the typed visitor.

Fixed-point mapping decodes typenum fraction parameters. The pinned metadata contains `FixedU128<Frac32>` for RootProp and MinerBurned, so its exact unsigned wrapper is `U96F32`. Unsupported mapped fractions fail. Compact subnet text retains exact bytes and encodes each byte as Compact<u8>; threshold and non-UTF8 tests prevent an ordinary Vec<u8> encoding from replacing it. Eleven generated model-field descriptors carry CompactBytesText, StakeWeight, PriceRao, and packed NetUidStorageIndex semantics. DynamicInfo's subnet_name and token_symbol require compact byte elements; SubnetPrice.price requires native u64 and explicit PriceRao semantics. The packed netuid override follows get_mechagraph, which stores the mechanism index in the NetUid-shaped field.

All 31 configured struct models have their declared field names and Rust types checked against pinned metadata on every regeneration, including the complete required semantic override set. Four typed enum contracts cover Data, HyperparamValue, ProxyType, and Bounded (CrowdloanCall). Enum declarations include their variant order; the checker verifies the complete metadata variant set, names, SCALE indices, payload field names, and mapped Rust types. Data's single Raw(Vec<u8>) arm expands to all 129 Raw0 through Raw128 metadata variants. Each must have one fixed byte array of exactly the named length. H256 payloads used as [u8;32] must retain their validated one-field byte-array wrapper. A new enum variant, changed payload, changed raw length, or changed index fails model checking. Generated enum surfaces use Projection::Exact, including when nested in a projected struct, so live additions also refuse typed use.

Struct mappings require explicit declared-field lists. Generated factories project API outputs through optional, sequence, array, tuple, compact, and BoundedVec wrappers; live verification uses the same factory. Missing declared fields and changed field types refuse typed use. Unknown named models follow the DynValue fallback and retain exact output checks. Recursive configured struct declarations fail generation rather than producing an incomplete projection. `regen --models-only` validates source declarations, semantic wire forms, enum contracts and frozen source snapshots without changing generated files.

Every regeneration also verifies command-generated frozen model tripwires against literal freeze_struct attributes from the pinned rpc_info sources. A changed snapshot requires deliberate review and update. Headers omit spec versions. The System.Version descriptor retains its live name and type but excludes its runtime-dependent value and verification entry. Optional storage values carry an OptionalStorage marker so typed missing reads return Option; descriptor.at binds unhashed keys in StorageQuery. A generator test changes both the supplied spec and the entire encoded System.Version constant and gets identical generated bodies. Output is sorted and formatted by the pinned toolchain. `regen --check` compares every expected generated file and rejects orphan files.

Shape hashing uses the same source in the runtime crate, generator and drift command. Exact hashes retain argument names, order and wire structures. Projection hashes check only declared fields, recursively, and tolerate appended fields. The three outer runtime enums contribute distinct opaque markers, so a new unrelated pallet call does not alter Utility, Multisig, Proxy, or Sudo wrapper hashes. Bit sequences retain a validated Lsb0/Msb0 order tag because the two empty marker structures have different wire meaning.

Recognized substrate_fixed numbers additionally hash the SCALE tuple ("F", signed: bool, width: u32, fraction_bits: u32, structural_hash: [u8;32]). FixedI128<Frac32> and FixedI128<Frac64> encode identical i128 bits but interpret those bits differently. The parser validates the single bits field's primitive, sole fraction parameter, UInt parameter/field alignment, empty UTerm/B0/B1 markers, checked arithmetic, and fraction <= width. Unknown or malformed semantic markers fail closed. Type-parameter names, documentation, ordinary type aliases, and semantic-family module moves do not affect the hash. The public ShapeHasher::fixed_semantics helper uses the same validator for field-local interpretation guards. Both exact and projected model/API gates refuse a real pinned metadata mutation from Frac32 to Frac64.

Traversal rejects malformed registries and projections and has 128-level depth and 65536-node work bounds, including fraction traversal. The depth limit remains below the default test-thread stack capacity; an adversarial deep registry returns an error.

RuntimeHandle owns immutable parsed metadata, name caches, structural hashes, the surface report, and a cached RFC-0078 digest. V14 remains readable and refuses call composition and digest signing. Unknown extensions with nonempty payloads and unsupported extrinsic versions disable signing before a call is composed. CallBytes stamps both runtime versions, and every nested typed call must match both. Generated calls use the core's `compose_call` encoder after checking their own descriptor, so unrelated drift does not prevent a compatible call.

Validation after the surface review corrections:

- Runtime unit tests: 49 passed, including the full generated descriptor inventory, model/core comparisons, unrelated additions, per-call refusal, V14, extension guards, stamps, projections, fixed semantic validation and digest agreement.
- Generator tests: 14 passed, covering six generation tests, five model/source tripwire checks and three namespace generator checks. The shared 22 shape tests run in the runtime suite; generator and drift use that crate's canonical shape types and implementation.
- Runtime integration tests: exact enum additions refuse both the enum and containing model; fraction changes refuse exact/projected model and API gates. Both passed.
- Generated semantic metadata tests: 5 passed, including path-only aliases, packed mechanism indices, and live API projection tolerance and refusal.
- Typed golden call test: all ten original spec-461 vectors pass through actual generated builders and `Call::compose`, including all nested calls and stamp checks.
- Compact text test: passed, including metadata-directed decoding and bytes at the compact threshold.
- Runtime strict Clippy and Rust 1.89 checks: passed.
- Xtask Rust 1.89 all-target check: passed. Its latest strict Clippy run reaches one unrelated extraction lint, invalidate_block's receiver is only used in recursion; the extraction owner has the correction request.
- `cargo xtask regen --check`: passed against repository-pinned metadata and all five Python descriptor files.

The final review corrections are verified. Surface reports require checked membership before an individual descriptor can pass its shape gate. Type identities remain descriptive; argument names and structural hashes decide encoding compatibility, so an unrelated leaf type alias does not refuse an unchanged call. Both corrections have regressions. The test harness directory used by the handle worker was removed after a process, launchd, configuration, symlink, and virtual-environment audit. The shared task build cache remains a live dependency of the ongoing plan execution.
