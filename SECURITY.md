# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's
[Report a vulnerability](https://github.com/sam0x17/rtao/security/advisories/new)
form, which opens a private security advisory on
[sam0x17/rtao](https://github.com/sam0x17/rtao). Do not open a public issue,
pull request or discussion for a suspected vulnerability.

Include the affected commit, crates and features, a description of the impact,
and steps or a test that reproduce the problem. Do not include real wallet
secrets, mnemonics or passwords in a report.

## Supported versions

rtao has not yet been released. Security fixes are made on the latest `main`
branch only; update to the newest reviewed commit to receive them.

## Past reviews

Reports from earlier security reviews of the codebase are kept in
[`docs/security/`](docs/security/).
